# SAMERIDER 開発・配布

## Windows版

既存のWindows向け発行は `scripts/publish-windows.ps1` を使用します。Windows版は従来のJSON＋`SAMERIDER_Import`画像フォルダー形式と、画像同梱の`.samerider`プロジェクトbundleの両方を読み書きできます。

## ブラウザ版（WebAssembly）

ブラウザ版はサーバー側へ画像をアップロードせず、PNG/GIFの読込とPNGの編集・出力をブラウザ内で行います。GIFを読み込むと、各フレームを連番PNGに変換してセルへ配置できます。Web版では`.samerider`を読み書きできます。Windows版の旧JSONをWeb版で開く場合は、JSONを選んだ後、表示される画像ごとの選択ダイアログで対応するPNGを選んでください。プロジェクト内に同名PNGがある場合も、ダイアログに表示される参照先パスを確認して個別に割り当てます。画像は個別128MiB、合計512MiBまでです。

### 発行

初回のみ.NET 8向けWebAssembly workloadを導入し、Release発行します。GitHub Pagesでは`.github/workflows/pages.yml`が`main`へのpush時に自動ビルド・公開します。初回はGitHub Settings → Pages → Build and deployment → SourceをGitHub Actionsに設定してください。

```sh
cd developer
dotnet workload install wasm-tools-net8
dotnet publish src/SAMERIDER.Browser/SAMERIDER.Browser.csproj -c Release
```

発行後、次のディレクトリの内容を静的ホスティングへ配置します（SDKによって出力先が異なります）。

- `src/SAMERIDER.Browser/bin/SAMERIDER.Browser/Release/net8.0-browser/publish/wwwroot`
- 旧SDKの場合: `src/SAMERIDER.Browser/bin/SAMERIDER.Browser/Release/net8.0-browser/browser-wasm/AppBundle`

### ローカル確認

発行ディレクトリをHTTPサーバーで配信してブラウザから開きます。例:

```sh
cd src/SAMERIDER.Browser/bin/SAMERIDER.Browser/Release/net8.0-browser/publish/wwwroot
python3 -m http.server 8000
```

`http://localhost:8000`を開いてください。ホスティング側は`.wasm`を`application/wasm`のContent-Typeで配信する必要があります。

`.samerider`はZIPベースの自己完結bundle形式です。ローカル配布・保存に対応しており、外部サーバーへの保存や同期は行いません。

## 非破壊編集

セル一覧の＋／−の隣から、次の編集ができます。編集値はプロジェクトに保存され、原本画像ファイルは変更しません。両操作ともUndo/Redoに対応します。

- **全体サイズ変更**: 現在のセル／シート寸法と縮小プレビューを確認しながらセル幅・高さを変更します。拡縮はNearest Neighborです。「スナップ」は、シートの幅・高さがそれぞれ4の倍数になる最寄りのセル寸法を選びます。実行後の「サイズ変更解除」で元の寸法に戻せます。切り出しサイズを変える場合は先に解除してください。
- **選択セルの色調変更**: 選択中の画像セルに色相・彩度・明るさ・コントラストを適用します。選択内に調整済みセルがあれば「色調変更を解除」に切り替わり、選択セルの調整を解除できます。全体サイズの解除と色調の解除は独立しています。

プレビューは上限付きの縮小画像から生成し、色調スライダーは更新頻度を制限して操作ごとの原本再デコードを避けています。

色調整の各項目には独立した「反転」があります。色相は180°回転、彩度はHSL彩度の反転（S → 1 − S、中間のグレーは赤系に変化）、コントラストは明暗関係の反転です。明るさの反転は最終RGBのネガポジ反転に対応し、透明度は保持します。反転だけの適用も保存・解除・Undo/Redoに対応します。

## 連番プレビュー

右カラムの「プレビュー」見出し横から、選択セルを左上から横書き順に15fpsでワンショット再生できます。未選択または1セルだけ選択している場合はグリッド全体を対象にします。再生中は同じボタンで中止でき、終了時は元の編集プレビューに戻ります。選択範囲・原本・Undo履歴は変更しません。

右隣のプルダウンで「通常」「加算」「乗算」を選択できます。合成方式はプレビュー表示だけに適用され、PNG書き出しには影響しません。再生画像はバックグラウンドで少数フレームだけ先読みし、画像ファイルをUIスレッドで毎フレーム読み込まない構成です。

## Unity用.meta生成

PNG書き出し設定の「Unity用.meta生成」は、現在のセル分割を記録した`.png.meta`だけを書き出し、設定ウィンドウは閉じません。「OK」は従来どおりPNGだけを書き出します。各操作は1ファイルのみ保存します。選択セルのみの場合は、選択範囲の外接矩形に合わせた分割情報になります。

PNGと同じファイル名＋`.meta`で保存し、PNGと同じフォルダーに配置してください。既存.metaのGUIDと同名Spriteの識別子は引き継ぎますが、それ以外のインポート設定は生成値（中央Pivot、100 PPU、Bilinear、FullRect、MipMapなし）へ更新します。meta保存後に選択範囲を変更した場合は再生成してください。

## セル一覧の操作

初期状態（空の1×1、シート名がSAMERIDER）へのPNG/GIF読み込みに成功すると、シート名を入力ファイルの拡張子なしの名前へ変更します。変更済みの名前は維持します。

右クリックの「空白セルを挿入」「セルを削除」は方向別のサブメニューです。「折り返す」は列数を維持して左上から横書き順にずらし、挿入時に必要な場合だけ行を追加します。空白セルも順番に含み、複数選択に対応します。折り返し削除後は末尾の空白行を取り除きます（最低1行）。

メニュー上部にはセル名を省略せず折り返して表示します。連番画像のセルでは、同じ場所の←／→でそのセルだけを前後の画像に差し替えられます。位置・色調・オフセットは維持し、先頭／末尾の方向は無効になります。これらの編集と初期読み込み時の名前変更はUndo/Redoで戻せます。

GIF配置の縦横数は連動し、一方を入力するともう一方を自動計算します。フレーム数を超える指定や末尾の空白行ができる指定は、フレームが収まる値に補正します。

「画像のセルサイズを指定」ではpxサイズと縦横分割数のどちらからも入力でき、相互に連動します。分割時に生じる右端・下端の端数は従来どおり切り捨てます。整数pxの等寸セルで指定数を作れない場合は読み込みできません。

読み込み時の初期セルサイズは画像縦横の最大公約数から求めます。分割数が上限を超える場合は、縦横がほぼ同寸になる少ない分割数を候補にします（例：1083×1448px → 361×362px、3×4分割）。既存セルがある場合は現在のセルサイズを維持します。
